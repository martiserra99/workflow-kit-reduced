# Workflow Kit

A complete workflow engine built on top of React Flow — with layout algorithms, drag-and-drop, undo/redo, MVC architecture, error detection, JSON serialization, and more. Save months of engineering time and plug a production-ready workflow system directly into your product.

---

## 🚀 Overview

Workflow Kit gives you all the essential building blocks of a fully functional workflow editor so you don't need to build them yourself. Instead of spending months implementing layout logic, MVC structure, undo/redo, interactions, and error handling, you can focus entirely on your product logic.

This is the same system powering **Formity UI**, and it has been **featured on the official React Flow showcase**.

---

## 🛠️ Getting Started

Install dependencies:

```bash
pnpm install
```

Run the project:

```bash
pnpm run dev
```

## ✨ Features

### React Flow, Made Simpler

An abstraction layer that gives you a clean, organized API for interacting with React Flow without managing low-level details. Build complex workflows with far less code.

### Node Layout Algorithm

A built-in automatic layout algorithm organizes nodes into clean, readable structures — no more manually arranging nodes or writing custom layout logic.

### Model View Controller Architecture

A complete MVC structure separates your workflow logic, view representation, and interaction layer. Maintainable, extensible, and built for real-world complexity.

### Built-In Drag and Drop

Drag nodes into your workflow with a smooth, pre-implemented drag-and-drop system. No event juggling or custom handlers needed.

### Undo and Redo System

A fully integrated undo/redo history tracks every change. Navigate through edits safely without building your own history logic.

### Detect and Show Errors

Run validation whenever you choose. The system scans workflows for invalid states and clearly shows the issues so users can fix them quickly.

### Workflow to JSON

Serialize any workflow into a structured JSON format for persistence, syncing, versioning, or backend processing.

### Full Documentation

Every feature is fully documented with clear examples, making integration and customization straightforward.
